Quake Watch — Live multi-source earthquake monitoring dashboard. Directly aggregates telemetry feeds in the browser across the United States Geological Survey (USGS), the Japan Meteorological Agency (JMA), and the European-Mediterranean Seismological Centre (EMSC).

### Key Highlights & Architecture

1. **Direct In-Browser Ingestion**: Fetches live data feeds from USGS, JMA, and EMSC endpoints directly from the browser client without intermediate server proxies. Every remote endpoint provides open CORS permissions.
2. **Spatio-Temporal Deduplication**: A single physical seismic rupture is frequently picked up by multiple international agencies. The deduplication algorithm merges events within $|\Delta t| \le 120\text{ seconds}$, $|\Delta\text{lat}| \le 1.0^\circ$, and $|\Delta\text{lon}| \le 1.0^\circ$, aggregating reporting source badges while retaining the highest reported magnitude.
3. **Magnitude vs. Intensity Disambiguation**: Correctly delineates between physical moment/surface magnitude ($M$) and JMA's localized *shindo* (震度) seismic intensity scale (e.g., `M4.0 · Max Shindo 2`), preventing common classification ambiguities.
4. **Interactive Map & Graceful Degradation**: Powered by dark-mode Leaflet vector markers scaled geometrically by magnitude and ramped across four risk tiers: green ($<5.0$), yellow ($5.0\text{--}5.9$), orange ($6.0\text{--}6.9$), and red ($\ge 7.0$). In the event of network disconnection or CDN unavailability, the application degrades gracefully to table-only monitoring.
5. **Auto-Polling & Opt-in Alerts**: Features a 60-second background auto-refresh interval with glowing badges for newly arrived quakes, plus user-consented desktop notifications for high-magnitude events ($M \ge 6.5$).
